# gestao-financeira

Wrapper GitHub Pages do app **Gestão financeira** (#10 da bancada Apps Script, v2 — ORD-FINANCEIRO-001).
Embute a `/exec` do Apps Script num `<iframe credentialless>` para contornar o roteador `/u/N/` do Google,
e trata a safe area do celular por fora (dentro do iframe ela vale zero).

Fonte de verdade: `implementacoes/appscript/projetos/PESSOAL/PRJ FINANCEIRO APP/wrapper/` no repo `cephalon`.
